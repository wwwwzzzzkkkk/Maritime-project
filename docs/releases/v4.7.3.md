# v4.7.3 · Reliable dialog motion and compact evidence layout

2026-10-22 · [Live website](https://wwwwzzzzkkkk.github.io/Maritime-project/)

Baseline: current repository `main` at `0c42af3` (v4.7.2).

- Form dialogs now animate with the Web Animations API. The dialog remains in the native top layer until the exit fade ends, so entry and exit do not depend on discrete `display` / `overlay` transitions. Escape, backdrop, close buttons, save-and-reset sequencing, interrupted reopen and reduced-motion behavior are retained.
- The policy evidence view shows expandable source items in two desktop columns and one narrow-screen column. Primary actions sit side by side; metadata spacing is tighter across evidence, fleet and action records.
- No calculation, policy data, external source or backend behavior changed. UI/cache/snapshot/report version: 4.7.3; cloud knowledge: 4.7.1; engine: light-4.2.0.
- GitHub Pages deploys from `main`. Browser-level checks could not run in the release environment because no browser binary was present and the Playwright browser download returned a truncated archive; the automated Node suite passed.
