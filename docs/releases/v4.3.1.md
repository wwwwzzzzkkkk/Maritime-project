## 中文

- 默认显示五个数值输入：范围内燃油消耗（等效吨）、基准燃油价、低碳燃料溢价、组池报价、允许增加的航时。组池可用量在报价旁显示，通过“修改”进入高级区。
- 新增输入适配模块，复用引擎已经导出的 41,000 常量。默认 4,000 等效吨对应 164,000,000 MJ；只按 VLSFO 等效解释，不能作为所有燃料的通用质量换算。能源只有一份 MJ 状态，快照不新增吨数字段。
- 保留原 14 个字段及其 min/max/step。高级区按燃料与价格、组池、运营限制分组；默认值计数、单项还原和 ⓘ 说明支持键盘操作，完整保留原有范围及免责说明。
- 当前假设标签来自已应用状态，可定位输入并自动打开高级区；未应用草稿明确提示。空值、越界、步长及非整数 MJ 换算错误显示双语行内提示，阻止非法数据进入计算。
- 四个演示预设：基准＝燃料 0% / 航速 0.0 kn / 组池 0；慢航只设 −1.0 kn；低碳燃料只设 20%；组池抵扣只设 200 tCB。其他滑块及价格、能源、供给、确认状态保持不变。慢航预设可能超出默认 24 小时限制，保留此提示。
- 三条声明合并为一次确认，底层三个标志与门控不变。演示按钮恢复当前船舶表单默认值并确认，不修改滑块；注明“仅用于演示，不代表真实核验”。重置恢复未确认；应用修改后的表单也撤销原确认。
- 保留默认玻璃风格、原动效、浮窗、EUR/GBP 分列及全部数据／法律边界。五个受保护文件不变，不改计算引擎、搜索算法，也不增加 CSV 导入或性能工作。

## English

- Show five quick numeric inputs: scoped fuel in equivalent tonnes, base fuel price, fuel premium, pool quote and allowed extra sailing time. The pool quote row links to advanced availability editing.
- Add a UI-only adapter using the engine's existing exported 41,000 constant. The default 4,000 equivalent tonnes equals 164,000,000 MJ; this is VLSFO equivalence, not universal fuel-mass conversion. MJ remains canonical and the snapshot has no tonne field.
- Retain all 14 original fields and their min/max/step, grouped advanced assumptions, default counts, restore actions and keyboard-operable explanations. Preserve scope and disclaimer text.
- Link applied-assumption tags to inputs and label unapplied drafts. Localized inline errors block invalid input without sending NaN into calculations.
- Four explicit demo presets only set existing sliders; non-baseline presets retain other sliders. Prices, energy, supply and confirmation do not change. The −1.0 kn speed demo can exceed the existing time constraint.
- Consolidate three declarations into one confirmation action while retaining underlying flags/gates. Demo confirmation restores active-vessel form defaults, leaves sliders unchanged and is explicitly not verification. Reset or applying edited inputs clears confirmation.
- Preserve glass materials, motion, floating budgets, protected sources, currency separation and all regulatory/data limitations. No engine/search changes, CSV import or performance work.
