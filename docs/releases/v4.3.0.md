Baseline: `light-v4.2.1-baseline-2026-10-16` (`cdec884`). Pure CSS consolidation is isolated in `86d3f20`, before the independent text/interaction commit.

## 中文

- 增加文字专用颜色令牌，保留装饰 accent 与默认玻璃材质；小字最低 12px，正文 15px，KPI 数值 30px。真实截图背景像素取样显示：公式文字 4.056→5.876、展开摘要 3.963→5.742、页脚 4.055→6.456；其余关键样本也保留完整记录。
- CSS 去重整理先单独提交。相同窗口/动画时刻的 1440、768、375 截图不同像素数均为 0；之后的文字变化是有意的可读性调整。
- 只处理指针命中的卡片及父层，每帧合并事件；只有指针进入表格/来源正文才平滑归零，标题和其他展示区域仍可倾斜。sticky 阅读区偏移实测 0px，原先约 2px 的问题通过局部例外处理，不是整卡或全局删除倾斜。
- 系统减少动态偏好下完全关闭倾斜，概览快速调节器保持平面。常驻 will-change 改为仅倾斜/导航动画期间启用。
- range input 由 scheduleRender 按帧合并；地图弹窗在打开时计算内容、打开期间更新，不再每次 render 重复绑定。行内样式迁为类，动态宽度使用 --w。
- 保留默认光斑与折射。无 GPU 成本结论、性能预算或速度提升声明。仅保留一个小型不支持 backdrop-filter 时的不透明底色回退。
- 本阶段评估过清爽模式，按用户决定取消。本版不提供切换、data-style=clean、localStorage、aria-pressed 风格控件或 prefers-contrast 自动模式。性能前后对比与三次中位数也已取消，不交付性能表。
- 纠正的初始判断：缓存原本已为 4.2.1；徽章正文使用 secondary；Chrome 顶栏最终是普通 blur，而导航/KPI 使用折射。
- 五个受保护文件逐字节不变，默认金额与 EUR/GBP 分列、演示/未核验/CO₂/非法律意见/示例分摊边界均保留。

## English

- Improve copy-specific contrast and sizes while retaining decorative accents and the original glass material. Minimum CSS labels are 12px, body 15px and KPI values 30px. Sampled composited-background contrast improves for formulas, disclosure summaries and the footer; evidence includes coordinates and actual screenshots.
- Isolate CSS consolidation in its own commit. Controlled three-width captures are pixel-identical before intentional text changes.
- Delegate pointer work to the hover chain and one animation frame. Settle cards flat only inside table/reference reading regions; titles/display cards retain tilt. Preserve flat quick controls and respect reduced motion.
- Batch range inputs with scheduleRender, avoid repeated popup binding, move inline presentation into classes/custom width properties, and limit will-change to active interactions.
- Keep default ambient glows and refraction. Clean mode, automatic high-contrast mode, performance comparisons/budgets and GPU-cost evaluation were cancelled. Only a small unsupported-blur opaque-background fallback is added.
- Preserve protected files, calculation outputs, currencies and all model/legal boundaries. Cache/UI version is 4.3.0; calculation-engine version remains light-4.2.0.
