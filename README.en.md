# MAREG light edition

The original glass UI, fonts, palette, pointer tilt, sliding navigation pill, panel transitions and chart replays are retained. This update changes layout, calculation correctness and evidence wording.

[Run and minimal checks](README.md) · [Model scope](docs/LIGHT_EDITION.md) · [Rollback](docs/ROLLBACK.md)

Data is illustrative. EU/UK ETS figures are CO₂ subtotals, not complete three-gas bills. FuelEU, speed, fuel and pooling use disclosed simplified assumptions. Real customer pilots, platform ESG measurements and external verification are not available.

The active-state JSON export is a calculation snapshot, not an authorized source ledger or human approval. Explanations are templates, without live AI/RAG. The other edition is unchanged. GitHub Pages follows main; branch changes become live after merging.
